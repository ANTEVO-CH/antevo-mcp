# Antevo Crypto Prices

One reference price per major crypto pair, with daily history and technical
signals on that same series — inside Cursor.

**Public. No account, no key.** Install it and start asking.

`https://api.antevo.ch/mcp/crypto/mcp`

## What you can ask

- What is bitcoin worth, and how did it move on the day?
- How has ETH/EUR moved over the last quarter?
- What does the technical picture look like for SOL/USD?
- Which pairs does Antevo price?

## What the price is

A composite across major exchanges, volume-weighted, with outlying quotes
excluded. Whole UTC days only — a daily reference price, not a live or tradable
quote. Technical signals are indicator readings, not investment advice.

## What it will not do

Every tool is read-only. Nothing here can place a trade, move money or change a
record. Every answer carries its source and its date.

Full tool list: <https://antevo.ch/mcp>
