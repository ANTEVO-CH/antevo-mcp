# Antevo Trademark

**Is that name taken? Check it across 50+ trademark registers.**

Screen a brand name, or a whole shortlist, against 50+ national and regional
trademark registers, with the companies and domains already registered under each
name. Read a holder's filing pattern, see which Nice classes a business files in, and
check an office's opposition window with the provision it comes from.

**Public. No account, no key.** Remote MCP server over Streamable HTTP:

`https://trademark.antevo.ch/mcp`

## Install in Kiro

Powers → Add Custom Power → import from GitHub:
`https://github.com/ANTEVO-CH/antevo-mcp/tree/main/powers/antevo-trademark`

## What you can ask

- Is "Meridian" taken as a brand name, and in which classes?
- Rank this shortlist for a fintech app: Lumira, Qzvexanth, Velora. Which already
  have trademarks, companies or domains under them?
- Which Nice classes does a business like mine file in?
- How long do I have to oppose a filing at the EUIPO, and from when?
- How long in Japan? (It runs from registration, not publication — that is the
  trap this answers.)

## What it will not do

Every tool is read-only. EU marks come from EUIPO's search at the time you ask; the
other trademark registers are read from Antevo's copy, refreshed from each office, so
a filing from the last few days can be missing. Company names come from the Swiss
commercial register (Zefix), and from Companies House and ACRA when you ask about the
UK or Singapore; domains from each registry's own lookup service. A source that does
not answer is reported as not checked, never as nothing found.
This is not legal advice.
